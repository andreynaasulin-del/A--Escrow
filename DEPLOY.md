# 🚀 Railway Deployment Guide

## Быстрый деплой:

1. **Открой Railway Dashboard**: https://railway.app/dashboard
2. **New Project** → **Deploy from GitHub repo**
3. **Выбери репозиторий**: `andreynaasulin-del/A--Escrow`
4. **Добавь Environment Variables**:
   - `BOT_TOKEN` = твой токен от @BotFather
   - `OPENAI_API_KEY` = твой OpenAI ключ
   - `ADMIN_ID` = твой Telegram ID
   - `WALLET_ADDRESS` = твой TRC20 кошелёк

5. **Deploy!**

## Environment Variables:

Скопируй значения из своего локального `.env` файла.

**ВАЖНО:** Не коммить реальные ключи в GitHub!

## После деплоя:

Бот автоматически запустится 24/7!
Логи доступны в Railway Dashboard.
